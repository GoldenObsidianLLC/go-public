## Project documentation rules

The VirgoScorpio Hub and EnginEx pages are review-stage drafts, not approved product announcements. Use the [product showcase template](../templates/product-showcase-template.md) for additional pages only when an authoritative public source and disclosure approval are available. Each showcase must identify the authoritative source, state its current status, distinguish released capabilities from prototypes and plans, and support material claims with appropriate evidence.

Project-specific repositories remain authoritative for implementation, supported configurations, release records, and project licenses. Package versions are not formal releases unless backed by the project's release/tag records. This index should link to those sources instead of duplicating their specifications or changelogs.

Do not publish private architecture specifications, unreleased security details, source code that is not approved for release, intellectual-property proofs, trade secrets, credentials, or confidential roadmaps in this public repository. See the [Licensing Policy](../05-governance-and-policies/licensing.md).
