# Governance and Policies

This section is the policy index for the public documentation vault. Each policy should have one canonical home; other pages should link to it instead of restating it.

## Canonical policies and references

- [Licensing Policy](licensing.md) — scope, attribution, code licensing, and protected-material exclusions.
- [Documentation Standards](../DOCUMENTATION-STANDARDS.md) — Markdown structure, frontmatter, naming, links, maintenance, and versioning.
- [Contributing Guide](../CONTRIBUTING.md) — issue, pull-request, and review expectations.
- [Security Policy](../SECURITY.md) — safe handling and reporting of security concerns.
- [Roadmap](../ROADMAP.md) — planned governance, content, and automation work.

## Governance principles

Public information should be accurate, attributable, maintainable, and safe to disclose. Policies should be changed deliberately, with the reason and impact recorded in the pull request. When policies overlap, prefer the document explicitly designated as canonical in the list above.

Protected intellectual property and confidential operational material are not made public merely by placing a notice or label on them. They must remain outside this repository.
