# Licensing Policy

This document is the canonical statement of licensing scope for the public documentation vault. It uses separate terms for different kinds of material; no single blanket license applies to every item in the repository.

## Documentation and prose — CC BY 4.0

Original documentation, prose, guides, articles, and other public written material are made available under the [Creative Commons Attribution 4.0 International License](https://creativecommons.org/licenses/by/4.0/), unless a file states a different applicable license or is identified as third-party material.

When reusing this material, provide appropriate credit to Golden Obsidian LLC, link to the license, identify changes when practical, and do not imply endorsement.

## Code snippets and helper scripts — MIT

Code snippets and helper scripts intentionally published in this repository are made available under the [MIT License](https://opensource.org/license/mit), unless a file contains a more specific notice. Standalone code files should include an SPDX license identifier or an adjacent license notice.

Code embedded in a documentation page is licensed separately from the surrounding prose: the prose remains CC BY 4.0 and the code snippet is MIT. Preserve this distinction when copying or adapting examples.

## Explicit exclusions — All Rights Reserved

The following materials are excluded from the public license grants and remain All Rights Reserved:

- Intellectual-property proofs and evidentiary records.
- Detailed or non-public architectural specifications and proprietary technical designs.
- Trade secrets, confidential methods, and unreleased product details.
- Private security assessments, exploit details, credentials, keys, tokens, and confidential operational data.
- Third-party materials whose rights do not permit republication.

These excluded materials must not be committed to this public repository. A high-level public description may be published only after it has been independently reviewed and approved for disclosure. A license notice does not make protected material safe to publish.

## Third-party material

Third-party text, code, diagrams, screenshots, logos, and other assets retain their original terms. Record the source and license or permission where applicable. Do not assume that a repository-level policy overrides third-party rights.

## Mixed-license repository handling

A root-level LICENSE file is intentionally not used because it could incorrectly suggest that one license governs every file. This policy is the canonical licensing reference. Individual files and code samples should carry clear notices when their scope is not obvious.

When in doubt, do not publish or reuse the material until ownership, permission, attribution, and the intended license have been confirmed.
