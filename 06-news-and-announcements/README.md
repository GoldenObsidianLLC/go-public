# News and Announcements

This section contains dated, public-facing updates from Golden Obsidian LLC and its ecosystem.

## Intended contents

- Company announcements and public articles.
- Product news and release announcements.
- Event notices and community updates.
- Editorial updates that materially change previously published public information.

## Publishing guidance

Use a date-prefixed filename in YYYY-MM-DD-title format. Include the publication date, distinguish confirmed facts from plans, and link to the canonical project page or release record. Do not duplicate full release notes maintained in a project's own repository; summarize the announcement and link to the canonical source.

The root [Changelog](../CHANGELOG.md) is the canonical record of versioned changes to this documentation repository. This section is for reader-facing communications, not a second changelog.

Verify claims, quotations, screenshots, benchmarks, and third-party references before publication. Do not publish confidential launch details or unreleased information.
