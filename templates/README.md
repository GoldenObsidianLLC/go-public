# Markdown Templates

Use these templates to create consistent, reviewable documentation.

## Available templates

- [General Document](document-template.md) — guides, references, FAQs, and policy drafts.
- [Product Showcase](product-showcase-template.md) — public-facing overviews of products and projects.

## How to use

1. Copy the closest template into the appropriate section.
2. Rename the file using lowercase kebab-case. Use the date-prefixed convention for news and announcements.
3. Replace every placeholder and complete the frontmatter using [Documentation Standards](../DOCUMENTATION-STANDARDS.md).
4. Remove sections that do not apply; do not leave empty headings or instructional placeholder text.
5. Check the source, license, attribution, links, status, and public-disclosure boundaries before requesting review.

Templates are starting points, not mandatory page layouts. Keep the final document as short as the subject allows and link to canonical sources instead of duplicating them.
